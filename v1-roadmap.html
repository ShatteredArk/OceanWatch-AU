Critical path — oil detection options
Cerulean / SkyTruth API
Low effort
Cerulean (by SkyTruth) is a REST API returning confirmed SAR-based oil detections globally. Coverage includes Australian waters. Returns GeoJSON polygons with confidence scores — maps directly onto the existing schema.
  • Detection already done — API returns slick polygons, not footprints
  • Confidence scores align with existing tier logic
  • Minimal code change: swap CDSE fetch → Cerulean fetch in ingest.ts
  • Commercial — requires subscription / API key
  • Latency depends on provider update cadence
EMSA CleanSeaNet
Medium effort
European Maritime Safety Agency operates a SAR-based oil spill detection service. Coverage is primarily European waters; Australian coverage is limited or absent in the standard offering.
  • Official governmental service — high credibility
  • Validated detections with confidence scoring
  • No AU/Pacific coverage in standard tier
  • Requires formal agreement / bilateral data sharing
  • API not publicly documented
Build SAR dark-spot detector
High effort
Process raw Sentinel-1 GRD imagery via SNAP or Google Earth Engine to identify SAR dark-spots (low backscatter), then classify oil vs look-alike (wind shadow, biogenic film, rain cells) using a trained ML model.
  • Full control — custom confidence scoring possible
  • No external dependency or ongoing API cost
  • Months of ML/RS engineering effort
  • High false-positive rate without extensive training data
  • GEE or cloud compute cost for ongoing processing
